# 整车零部件学习手册（采购/SQE 方向）

> 从零机械基础到能跟供应商对话——整车 8 大系统域、51 个一级零部件的深度图解手册。

## 这本书怎么用

每章一个系统域，每个零件一个独立小节，统一按六个视角拆解：

| 小节 | 回答的问题 |
|---|---|
| 一句话定位 | 这个零件是什么（生活化类比） |
| 结构组成 | 它由哪些二级件构成，各起什么作用 |
| 工作原理 | 为什么这么设计 → 如何工作 → 达成什么效果 |
| 采购关注点 | 技术路线差异、成本构成、定点谈判要点 |
| 跨域接口 | 它跟其他系统交换什么（力/电/信号/热量），方向与逻辑 |
| 供应商风险 | 市场格局、断供/质量/技术迭代风险 |

**学习顺序建议**：04 车身（建立空间感）→ 03 底盘 → 01/02 动力（燃油与三电对照着学）→ 06 热管理 → 07 座椅 → 08 被动安全 → 05 电子电器（最抽象放最后）。

## 图片占位使用说明

正文中所有图片位置都是如下格式的占位块：

> **【图 04-03｜车门总成结构爆炸图】**
> 图注：这张图展示了什么、看哪里。
> 配图说明：这张图绑定正文哪个知识点。
> 图片链接：![图04-03 车门总成结构爆炸图](PLACEHOLDER-04-03)

**替换方法**：把你自己的图片上传到图床或网站 images 目录，然后把 `PLACEHOLDER-04-03` 替换成真实图片地址即可，图名、图注、配图说明已为你写好，无需改动。编号规则：`图X-NN` = 第 X 章第 NN 张图。
